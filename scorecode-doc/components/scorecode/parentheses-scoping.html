Parentheses/scoping

A lone parentheses is a scoping operator.
Expressions within a parenthesis will be evaluated independently and the result will be returned, ignoring operator precendence.

Examples

Overriding operator precedence - without parentheses, * binds tighter than +. Parentheses force the addition to happen first.

[[codebox:(2 + 3) * 4 -> 20 // (2+3)*4 = 20, parentheses win (1 | 0) & 0 -> 0 // OR is grouped first, then AND (1 | 0) * 4 -> 4 // If parenthesis not present, it would evaluate to 1]]
