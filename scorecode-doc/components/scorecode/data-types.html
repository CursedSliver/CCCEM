Types

There are only three types of data in Scorecode: numbers, strings, and functions.

Numbers are the same as JS numbers, which is a double following the IEEE 754 standard.
When evaluating boolean expressions, 0 is considered false, and all other numbers are considered true. Boolean operators also return 0 or 1.
Functions are called lambdas, and can be passed around like numbers. However, some operations only work on numbers. For more information, check out the Functions page.
Strings exist but cannot be manipulated or read with normal operations; the only operation allowed is =. Methods to interface with strings exist via various watchers that offer such functionalities.
