Constants

You can specify any number to create a fixed number at that point in the formula.
Constants are useful for specifying a fixed value, such as the number of seconds in a minute.
You can also specify true for 1, and false for 0.
Note that E-based scientific notation is NOT supported. (e.g. 1e-3 is not supported)

To create a string, use the [str;arg] Watcher, replace arg with text. Note that strings can only be manipulated and read through Watchers.
