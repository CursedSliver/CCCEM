Comparison operators

A comparison operator takes in two expressions and returns a pesudo-boolean value (in other words, 0 for false, 1 for true).
There are three types of comparison operators.

Operator Description
<expr> < <expr> Greater than: Returns 1 if the first expression is greater than the second expression, otherwise 0.
<expr> = <expr> Equal to: Returns 1 if the first expression is equal to the second expression, otherwise 0.
<expr> > <expr> Less than: Returns 1 if the first expression is less than the second expression, otherwise 0.

Return value

All comparison operators return numbers: 0 for false, 1 for true.

Examples

Less than (<) - returns 1 when the left side is strictly less than the right side.

[[codebox:1 < 2 -> 1]]

Greater than (>) - returns 1 when the left side is strictly greater than the right side.

[[codebox:2 > 1 -> 1]]

Equal to (=) - returns 1 when the two sides are exactly equal. Note the single =; there is no == or ===. Can be used on two strings to check for exact equality.

[[codebox:1 = 1 -> 1 1 = 2 -> 0 (2 + 2) = 4 -> 1 [str;yes] = [str;yes] -> 1]]
