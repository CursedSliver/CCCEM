Functions

A function is a block of code that can be called with variable inputs, and can be passed around as a value.
Functions can be called with the (<function>)@(<arguments separated by commas>) syntax.

Function declaration

Functions are declared with the (<arguments separated by commas>)#(<function body>) syntax.
Each argument name must be enclosed with single quotes ('), in both the argument declaration section AND in the function body.
The function body is another expression where all arguments, including any arguments in functions enclosing the current function, can be used, given that single quotes are used to enclose the names. In other words, a function creates a scope in which the arguments are available, and scopes can be nested within other scopes to make more complex functions.
This kind of argument encapsulation in nested functions is supported in functions exported from helper trackers, but the argument names need to match. This behavior is not supported in functions that passed into other functions.

Calling a function

Functions can be called with the (<function>)@(<arguments separated by commas>) syntax.
The arguments are expressions, and will be evaluated before the function is called.
The function will return whatever value is left when its inner expression finishes, and thus there is no need for a return statement.

Spread argument ("...")

A function can have a spread argument (...), which represents all remaining arguments passed into the function. It must be the last argument in the list.
When this argument is declared, the ... keyword becomes available in the function body, and can be passed into another function call to also pass its contained augments into the function.
The spread argument will only access arguments from the innermost function that wraps the token.

Examples

Declaring and calling a function - the body 'i' simply returns the argument.

[[codebox:('i')#('i') // identity function: returns its argument (((('i')#('i')))@(5)) -> 5 // 5 is passed in, 5 is returned]]

Multi-argument functions - arguments are separated by commas and must each be wrapped in single quotes.

[[codebox:('a','b')#('a' + 'b') // function that sums its two arguments ((('a','b')#('a' + 'b')))@(3, 4) -> 7 // 3 + 4 = 7]]

Nested functions and closures - inner functions can see the arguments of outer functions.

[[codebox:('i')#((('ii')#('i' + 'ii'))@(3)) // outer takes i, inner adds 3 ((('i')#((('ii')#('i' + 'ii'))@(3))))@(5) -> 8 // 5 + 3 = 8 ('x')#(('y')#('x' + 'y')) // curried addition: x + y ((('x')#(('y')#('x' + 'y')))@(2))@(3) -> 5 // 2 + 3 = 5]]

Functions are values - a lambda can be stored in another lambda's body and called later.

[[codebox:('f','x')#(('f')@('x')) // apply: call f with x ((('f','x')#(('f')@('x')))@((('n')#('n' * 2)), 7)) -> 14 // double(7) = 14 ((('f','x')#(('f')@('x')))@((('n')#('n' + 1)), 9)) -> 10 // add1(9) = 10 ((('f','x')#(('f')@('x')))@((('n')#('n' - 1)), 5)) -> 4 // sub1(5) = 4]]

Spread argument - the spread argument is a list of all remaining arguments.

[[codebox:('i', ...)#(('b', 'c')#('b' * 'c')@(...) + 'i') // multiply b by c, then add i ((('i', ...)#(('b', 'c')#('b' * 'c')@(...) + 'i')))@(1, 2, 3, 4) -> 14 ]]

Eager evaluation of arguments - arguments are evaluated before the function is called, so a function never receives unevaluated code.

[[codebox:('f')#((('x')#(('f')@(('x')@('x'))))@(('x')#(('f')@(('x')@('x'))))) // the famous Y combinator with the effect that Y(f) -> f(Y(f)), this does not work! ('f')#((('x')#(('f')@(('x')@('x'))))@(('x')#(('f')@(('x')@('x')))))@(('arg')#(1)) -> game freezes because of eager evaluation of arguments ('f')#((('x')#(('f')@(('v')#(('x')@('x')@('v')))))@(('x')#(('f')@(('v')#(('x')@('x')@('v')))))) // you actually need the Z combinator which circumvents this issue // though there is an easier way to recurse by making a helper tracker with ('f', ...)#(('f')@('f', ...))]]
