Math utilities

The language provides some base-level math utilities for your convenience.
There are 5 utility keywords.

Utility Description
<expr> min <expr> Takes the expression with the smaller value.
<expr> max <expr> Takes the expression with the larger value.
sin <expr> Takes the sine of the expression in radians.
cos <expr> Takes the cosine of the expression in radians.
tan <expr> Takes the tangent of the expression in radians.

Return value

All math utilities return numbers.

Examples

min - returns the smaller of two values.

[[codebox:3 min 5 -> 3 -2 min 4 -> -2]]

max - returns the larger of two values.

[[codebox:3 max 5 -> 5]]

sin - takes the sine of the next expression (input in radians).

[[codebox:sin 1 -> 0.8414709848078965 // sin(1 rad) sin (-1) -> -0.8414709848078965 // sine is odd: sin(-x) = -sin(x)]]

cos - takes the cosine of the next expression (input in radians).

[[codebox:cos 1 -> 0.5403023058681398 // cos(1 rad) cos (-1) -> 0.5403023058681398 // cosine is even: cos(-x) = cos(x)]]

tan - takes the tangent of the next expression (input in radians).

[[codebox:tan 1 -> 1.5574077246549023 // tan(1 rad)]]
