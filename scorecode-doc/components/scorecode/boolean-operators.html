Boolean operators

A boolean operator takes the values of the next expression (and sometimes previous expression) and returns a pesudo-boolean value (in other words, 0 for false, 1 for true).
The output of the previous or next expression is interpreted as a pesudo-boolean value: 0 for false, any nonzero value for true.
You can also specify "true" or "false" to substitute for 1 and 0.
There are three types of boolean operators.

Operator Description
<expr>&<expr> Logical AND: Returns 1 if both expressions are nonzero.
<expr>|<expr> Logical OR: Returns 1 if either expression is nonzero.
!<expr> Logical NOT: Returns 1 if the expression is zero, 0 if the expression is nonzero.

Precendence

! > & > |

Return value

All Boolean operators return numbers: 0 for false, 1 for true.

Examples

Logical AND (&) - returns 1 only when both sides are nonzero.

[[codebox:1 & 1 -> 1 1 & 0 -> 0 0 & 0 -> 0 5 & 1 -> 1 // any nonzero on both sides counts as true true & false -> 0 // you can also use "true" or "false" to substitute for 1 and 0]]

Logical OR (|) - returns 1 when either side is nonzero.

[[codebox:1 | 0 -> 1 0 | true -> 1 false | false -> 0 7 | 0 -> 1 // any nonzero on either side counts as true (0) | (0) -> 0 // nothing nonzero anywhere]]

Logical NOT (!) - flips a pseudo-boolean.

[[codebox:!0 -> 1 // 0 is false, NOT false is true !1 -> 0 // nonzero is true, NOT true is false !5 -> 0 // any nonzero value is treated as true !(3 - 3) -> 1 // 3 - 3 = 0, NOT 0 is true]]

Pseudo-boolean truthiness - any nonzero number (including fractions and negatives) is considered true.

[[codebox:0.5 & 1 -> 1 // 0.5 is nonzero, so it is true -1 & 1 -> 1 // negative numbers are also nonzero !0.0001 -> 0 // 0.0001 is nonzero, NOT nonzero is 0 0.0001 | 0 -> 1 // 0.0001 is nonzero, so the OR is true]]
