Math operators

A Math operator takes in two expressions and returns a number.
There are five types of math operators.

Operator Description
<expr> + <expr> Addition: adds the two expressions together.
<expr> - <expr> Subtraction: subtracts the second expression from the first expression.
<expr> * <expr> Multiplication: multiplies the two expressions together.
<expr> / <expr> Division: divides the first expression by the second expression.
<expr> % <expr> Modulo: returns the remainder of dividing the first expression by the second expression.
<expr> ^ <expr> Power: raises the first expression to the power of the second expression.

Return value

All Math operators return numbers.

Examples

All examples below are evaluated as standalone expressions and shown with their result.

Addition (+) - adds two numbers.

[[codebox:1 + 2 -> 3 10 + (-3) -> 7]]

Subtraction (-) - subtracts the right from the left.

[[codebox:5 - 3 -> 2 3 - 5 -> -2]]

Multiplication (*) - multiplies two numbers.

[[codebox:3 * 4 -> 12 -2 * 5 -> -10]]

Division (/) - divides the left by the right. Dividing by 0 returns 0 (it does not throw).

[[codebox:10 / 2 -> 5 9 / 2 -> 4.5 5 / 0 -> 0 // division by zero returns 0 0 / 0 -> 0 // 0 / 0 also returns 0]]

Modulo (%) - returns the remainder after dividing the left by the right. Modulo by 0 returns 0.

[[codebox:10 % 3 -> 1 9 % 9 -> 0 // a number mod itself is 0 5 % 0 -> 0 // modulo by zero returns 0 -7 % 3 -> -1 // JS-style sign of the dividend is preserved]]

Power (^) - raises the left to the power of the right.

[[codebox:2 ^ 3 -> 8 0 ^ 0 -> 1 // 0^0 is treated as 1 10 ^ 1 -> 10 // any number to the 1 is itself 9 ^ 0.5 -> 3 // square root: 9^0.5 = 3]]

Precedence and grouping - the standard math precedence applies, with ^ highest, then */%, then +-. Parentheses override precedence.

[[codebox:2 + 3 * 4 -> 14 (2 + 3) * 4 -> 20 2 ^ 3 ^ 2 -> 512 // right-associative: 2 ^ (3 ^ 2) = 2 ^ 9 = 512 8 / 4 / 2 -> 1 // left-associative: (8/4)/2 = 1]]
