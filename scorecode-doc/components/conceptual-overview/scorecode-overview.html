Scorecode overview

Scorecode is a custom programming language that is used in Trackers and Stats. (See High-level overview for more details)
It is an almost-pure functional programming language, similar to Haskell. For example, variables cannot be dynamically created or deleted, functions have no side effects, and the only inputs are values returned from Watchers. Functions are also first-class values.
Each Tracker holds exactly one number that is updated according to their own Scorecode formula, and that's all the "variables" available.

Language syntax overview

  • Types: numbers and functions. Non-zero numbers are considered true, zero is false.
  • Math operators: + - * / % ^
  • Boolean operators: | & !
  • Parentheses/scoping: ( )
  • Comparison operators: < > =
  • Branching: <expr returning zero or nonzero>?<expr if true>:<expr if false>
  • Constants: true false <arbitrary numbers>
  • Math utilities: min max sin cos tan (min and max go between two expressions like math operators, trig goes before expression)
  • Function declaration: (<arguments separated by commas>)#(<function body>)
  • Calling functions: (<function>)@(<arguments separated by commas>)
  • Iterations: (similar to Array.prototype.reduce in JS) (<iteration count){<body function>}(<accumulator function>)
  • Game state access:
    • Watchers: [<watcher name>;<arguments with or without $ before>]
    • Trackers: "<tracker name>"
    • Value of the tracker that the code is attached to: 'value'
    • CCCEM settings: [[<setting ID>]]
  • Ignored: ALL whitespaces not inside watcher names, tracker names, and CCCEM settings. Code does not have to be on one line. Comments are declared with //.
